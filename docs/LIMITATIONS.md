# Batas prototipe dan fase Android

- Aplikasi adalah usulan simulasi, belum layanan resmi dan bukan satu-satunya jalur bantuan darurat. Tidak ada data pasien nyata, kemampuan armada, cakupan, nomor layanan atau target waktu resmi yang dikarang.
- Tidak ada keputusan medis, penilaian lokasi pendaratan, persetujuan terbang, ETA atau rute otomatis. Haversine hanya jarak garis lurus. Peta Leaflet tidak memakai WebGL, geocoding, routing service atau API key. Marker menunjukkan data sintetis.
- Demo menyimpan data di perangkat, menyediakan pilihan peran simulasi dan bukan autentikasi. Connected memerlukan deployment Apps Script privat secara data, rahasia koneksi, origin HTTPS dan akun undangan. Aplikasi belum menjalani audit keamanan independen; hanya untuk data sintetis.
- Apps Script/Sheets belum diuji terhadap akun nyata. Pengujian backend menggunakan source dispatcher asli dengan adapter SpreadsheetApp/Properties/Cache/Lock mock. Kuota, OAuth, kebijakan Workspace, performa hash, redirect dan timeout deployment nyata belum terverifikasi.
- Tidak tersedia upload, push notification, WebSocket, offline tile cache atau pelacakan armada nyata. Inbox memakai ActivityLogs. Polling berinterval dengan backoff; bukan real-time tanpa jeda. Tidak mengirim data klinis pada notifikasi umum.
- Draft dan outbox dipisah menurut mode dan pemilik pengguna; tidak ditampilkan sesudah logout kepada peran demo lain. Public draft memakai ruang public pada perangkat yang sama; jangan memakai perangkat bersama untuk informasi sensitif. IndexedDB dapat dihapus atau dibatasi browser. Tidak ada sinkronisasi saat browser tertutup, tidak menjamin halaman baru dapat dibuka offline. Konflik memerlukan peninjauan, bukan last-write-wins. Outbox publik dapat dikirim ulang dari form oleh pemilik ruang lokal terkait. Jangan mengirim ulang dengan akun lain atau membuat operationId baru untuk mengatasi kegagalan parsial. Tidak ada pengiriman otomatis saat browser ditutup.
- Checklist dan catatan adalah teks terstruktur minimum berdasarkan misi, bukan formulir klinis baku atau checklist penerbangan resmi. Fasilitas disiapkan melalui seed dan editor Sheets privat; belum ada CRUD direktori di UI. Resources memiliki pembaruan kesiapan. Manajemen akun dan konfigurasi rahasia melalui editor administratif, bukan halaman pengaturan publik.
- Laporan PDF/CSV berasal dari data yang boleh diakses peran pengguna. Template PDF memakai font bawaan lokal, sehingga karakter di luar font standar mungkin tidak dirender sempurna. ActivityLogs memuat durasi sejak perubahan sebelumnya; bukan indikator resmi.
- Google Sheets tidak menyediakan transaksi penuh; journal Pending tidak dapat diputar ulang otomatis dan membekukan perubahan operasional baru hingga rekonsiliasi. Lihat prosedur rekonsiliasi. Owner spreadsheet masih bisa mengubah log dan data; tidak ada klaim audit tahan manipulasi.
- Rate limit memakai CacheService yang dapat dieviksikan dan lock global. Tidak ada perlindungan DDoS menyeluruh, MFA, reset password mandiri, daftar sesi pengguna, rotasi token otomatis atau registrasi publik.
- Tidak ada deployment publik dalam pekerjaan ini. Dokumentasi deployment perlu diverifikasi dengan sumber resmi ketika akses jaringan tersedia.

## Pengawasan pimpinan

`/pimpinan` adalah usulan tampilan simulasi, bukan sistem resmi Kasau/Kemenhan/Kemenkes/Presiden. Sudut pantau mengubah penyajian, bukan akses akun. Tidak ada integrasi identitas pejabat atau data pemerintah. Akun Viewer hanya memperoleh angka agregat; tidak memiliki akses data operasional rinci. Angka kesiapan berdasarkan status yang dicatat manual dan tidak membuktikan kapasitas armada, tempat tidur atau cakupan nasional. Periode menyeleksi kohor dibuat pada hari kalender UTC, bukan seluruh misi historis yang mungkin masih aktif; jumlah aktif di luar kohor ditampilkan terpisah. Durasi hanya sampel log dan tidak tahan manipulasi oleh pemilik Sheets. Dataset besar, koneksi Sheets nyata dan deployment Vercel tetap belum diuji.

## Persiapan APK berikutnya

Frontend memakai React/TypeScript dan boundary services terpisah. Fase berikutnya dapat menambahkan Capacitor dengan output Vite `dist`, izin lokasi berbasis tindakan pengguna, serta adapter penyimpanan sesuai kebutuhan. Jangan memakai shared secret di APK. Cookie same-origin dan validasi Origin connected saat ini dirancang untuk HTTPS web; origin WebView berbeda dan **belum didukung**. Autentikasi dan strategi API mobile memerlukan kajian tersendiri sebelum membungkus frontend. APK bukan deliverable fase awal.
